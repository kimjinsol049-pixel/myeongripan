# 명리판 (命理板)

생년월일시로 사주 원국을 세우고, 인원 제한 없이 궁합을 읽어 링크로 공유하는 정적 웹앱입니다.
서버 없이 브라우저 안에서만 돌아갑니다.

## 계산

- 천문 근사식으로 태양 황경(절기)과 삭(신월) 시각을 직접 구해 년·월·일·시주를 세웁니다.
- 음력·윤달 변환은 동지를 품은 삭망월을 11월로 두고 중기가 없는 달을 윤달로 잡는 표준 방식입니다.
- 한국 표준시 변천(1908·1912·1954·1961)과 역대 서머타임 12구간을 반영합니다.
- 일주 기준: `(율리우스일 + 49) mod 60 = 甲子`. 1900-01-01 甲戌, 1949-10-01 甲子, 2000-01-01 戊午, 2024-01-01 甲子로 검산.
- 시간 보정 기본값은 국내 만세력 관행인 표준시 −30분(동경 127.5°). 진태양시(경도+균시차)·보정 없음도 선택 가능.

## AI 해석

계산값(원국·오행·십신·합충·대운)을 근거로 Claude가 항목별 해석을 씁니다.

- 첫 화면 **AI 해석 설정**에 Anthropic API 키를 넣으면 켜집니다. 키는 이 브라우저의 `localStorage`에만 저장되고, 이 페이지에서 Anthropic API로 직접 호출합니다.
- 키가 없으면 계산 결과와 계산 기반 **핵심 판정**만 표시됩니다.
- 공유 코드에는 키가 들어가지 않습니다. "해석 포함" 공유는 생성된 글을 통째로 담아, 받는 사람은 키 없이도 그대로 읽습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `saju.js` | 천문 계산·만세력·사주·궁합 점수 엔진 |
| `interpret.js` | 명식 브리프와 항목별 프롬프트 |
| `rules.js` | AI 없이도 뽑는 계산 기반 핵심 판정 |
| `ai.js` | 해석 공급자 (claude.ai 아티팩트 `sample` → API 키 → 없음) |
| `app.js` | 화면·상태·저장·공유 |
| `styles.css` | 먹빛 기본 테마 + 한지 밝은 테마 |

## 로컬 실행

정적 파일이라 아무 HTTP 서버로 열면 됩니다.

```bash
python -m http.server 8080
```

`file://`로 직접 열면 공유 코드 압축(CompressionStream)은 동작하지만 API 호출은 CORS 정책상 막힐 수 있습니다.

## 주의

절기 경계 30분 이내 출생은 월주가 한 칸 달라질 수 있습니다. 사주는 통계와 상징의 언어이며 의료·법률·투자 판단의 근거로 쓰지 마세요.
